# 🧪 Inhouse TC Generator - Jira Plugin

Custom Jira Cloud app that displays test cases generated by the Inhouse TC Generator tool.

## Overview

This plugin adds a beautiful panel to Jira issues showing all test cases (QC-100, QC-101, etc.) that were generated from that issue.

**Features:**
- ✅ Displays generated test cases in a custom panel
- ✅ Shows QC numbers (QC-100, QC-101, ...)
- ✅ Links to test case issues
- ✅ Refresh button for real-time updates
- ✅ Clean, modern UI matching Jira design
- ✅ Fast load times
- ✅ Works on desktop and mobile

## Quick Start

### Prerequisites
- Node.js 14+ installed
- Jira Cloud account with admin access
- Atlassian account (create at atlassian.com)

### Installation (5 minutes)

**Step 1: Install Forge CLI**
```bash
npm install -g @atlassian/forge-cli
forge login
```

**Step 2: Setup Project**
```bash
cd C:\SymphonyProjects\automation-dashboard\jira-plugin
npm install
```

**Step 3: Run Locally**
```bash
forge tunnel
```

**Step 4: Test in Jira**
- Open your Jira instance
- Go to any issue with test cases
- Look for "🧪 Inhouse TC Generator" panel on the right

**Step 5: Deploy**
```bash
forge deploy
```

Done! The panel now appears in your Jira instance.

## Architecture

### Frontend (React)
- **File:** `src/index.jsx`
- **Features:**
  - Displays test cases in card layout
  - Refresh button to reload
  - Real-time status updates
  - Responsive design

### Backend (Node.js)
- **File:** `src/resolver.js`
- **Features:**
  - Fetches issue links via Jira API
  - Parses test case information
  - Extracts QC numbers
  - Handles errors gracefully

### Configuration (Manifest)
- **File:** `manifest.yml`
- **Declares:**
  - Module (issue panel)
  - Permissions needed
  - Backend resolver
  - App metadata

## How It Works

1. **User opens issue** in Jira (e.g., REB3-20607)

2. **Panel loads** on the right sidebar
   - Calls backend resolver with issue key

3. **Backend fetches data**
   - Gets all linked issues
   - Filters for "relates to" links
   - Parses QC numbers from titles

4. **Frontend displays results**
   - Shows each test case as card
   - Displays QC number, title, key
   - Provides link to test case

5. **User can refresh**
   - Click refresh button
   - Re-fetches latest data
   - Updates display

## API Integration

### Data Flow

```
Inhouse TC Generator Dashboard
  ↓ (generates test cases)
Jira API (creates issues)
  ↓
Test case issues created (REB3-20608, REB3-20609)
  ↓
Linked to parent with "relates to"
  ↓
Jira Plugin fetches links
  ↓
Panel displays in issue view
```

### Jira API Calls

The plugin uses Jira REST API v3:

```javascript
// Get issue with links
GET /rest/api/3/issues/{issueKey}?expand=changelog

// Returns:
{
  "key": "REB3-20607",
  "fields": {
    "issuelinks": [
      {
        "type": { "name": "relates to" },
        "outwardIssue": {
          "key": "REB3-20608",
          "fields": { "summary": "[TC: QC-100] Test Case Title" }
        }
      }
    ]
  }
}
```

## Customization

### Change Colors

Edit `src/index.jsx`, find `const styles = {...}`:

```javascript
qcNumber: {
  backgroundColor: '#0055CC',  // ← Change this
  color: 'white',
  ...
}
```

### Change Panel Title

Edit `manifest.yml`:
```yaml
title: "🧪 Custom Title Here"
```

### Add More Fields

Edit `src/resolver.js`, extend `parseTestCase()`:
```javascript
return {
  key,
  title,
  qcNumber,
  status,        // ← Add custom fields
  priority,      // here
  assignee,
  url
};
```

Then update `src/index.jsx` to display them.

## Troubleshooting

### Panel not appearing
```
1. Check: Forge tunnel still running?
2. Check: Hard refresh Jira (Ctrl+Shift+R)
3. Check: Console errors (F12)
4. Try: Restart tunnel and refresh
```

### Test cases not showing
```
1. Check: Issue has linked test cases?
2. Check: Links are type "relates to"?
3. Check: Test case titles have [TC: QC-100]?
4. Try: Click refresh button
```

### Deploy failed
```
1. Check: Node version >= 14?
2. Check: Logged in? (forge login)
3. Try: forge build first
4. Try: Clear npm cache (npm cache clean --force)
```
