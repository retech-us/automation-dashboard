# 🔧 Custom Field Setup - Manual Guide

Since the Jira API endpoint for field creation is not available, follow this **5-minute manual setup**:

## ✅ Quick Setup (5 Minutes)

### Step 1: Open Jira Settings
```
Go to: https://retech.atlassian.net/jira/settings/fields
```

### Step 2: Create Custom Field
```
1. Click "Create custom field" button
2. Select field type: "Text Field (Single line)"
3. Click "Create"
```

### Step 3: Configure Field
```
Name: Inhouse TC Generator
Description: Test cases generated by Inhouse TC Generator plugin

Searcher: Text field searcher

Click: "Create"
```

### Step 4: Assign to Screens
```
When asked "Which screens should this field appear on?"

Select:
✓ Default Screen
✓ REB3 Screens (if applicable)

Click: "Update"
```

### Step 5: Verify Creation
```
1. Go to REB3 project: https://retech.atlassian.net/browse/REB3-100
2. Edit an issue
3. Scroll down - you should see "Inhouse TC Generator" field
4. It should be blank initially
```

---

## 🚀 After Manual Setup - Resume Testing

Once the field is created in Jira:

### 1. Go Back to Dashboard
```
http://localhost:6060
```

### 2. Generate Test Cases
```
1. ⚡ Generate Test Cases tab
2. Select an issue (e.g., REB3-20607)
3. Click [Generate]
4. Approve a scenario
```

### 3. Check Jira
```
Go to your parent issue: https://retech.atlassian.net/browse/REB3-20607

You should now see:
✓ New linked test case issues created
✓ Custom field "Inhouse TC Generator" populated with links
✓ Example: "• [QC-100] [REB3-20608] - synced"
```

## ❓ Troubleshooting

### "Field doesn't show on issue"
```
1. Go to field configuration: Settings → Fields → Inhouse TC Generator
2. Click "Configure" → "Screens"
3. Make sure your issue screen is selected
4. Click "Associate"
```

### "Still not showing"
```
1. Hard refresh Jira (Ctrl+Shift+R)
2. Clear browser cache
3. Try opening a different issue and coming back
```

### "Test cases still not syncing"
```
1. Make sure custom field is created and visible
2. Go back to dashboard
3. Refresh: http://localhost:6060
4. Try generating and approving again
```
