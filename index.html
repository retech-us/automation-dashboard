    Sequencing Anomalies & Conflict Inspector

    Automated detection of Slot Collisions, Cyclic Deadlocks (Mutual Swaps), Directional Contradictions, and Redundant Moves
    🛡️ Sequencing Reality: 0 Cross-Product Collisions detected in both runs. Multiple actions targeting the same slot represent Legitimate Multi-Facing POG Blocks sharing an anchor position.
    STGSAMS: 0 Collisions, 2 Multi-Facing Blocks • KRCS: 0 Collisions, 6 Multi-Facing Blocks
    Instance Classification Target Anchor Facings (Exp / Act) Product & Movement Trajectory Collision & Sequencing Assessment
    💡 How Sequencing, Collisions & Physical Movements Work:
    • Why Cart Staging (KRCS) Avoids On-Shelf Collisions: In KRCS, the flow is Set Aside to Cart → Place from Cart. Because the shelf is completely cleared before items are placed back, on-shelf collisions are physically impossible — but this costs 153 physical shelf touches and 100% double handling.
    • How Direct Slides (STGSAMS) Are Derived: When products are moved directly on the shelf (`Fix in Bay`), we compare the starting slot to the target slot:
      • 👉 Slide Right (+N): Target Slot > Current Slot on the same shelf (e.g. Shelf 1, Slot 2 → Slot 3).
      • 👈 Slide Left (-N): Target Slot < Current Slot on the same shelf (e.g. Shelf 5, Slot 7 → Slot 5).
    • What is a Mutual Swap ($A \leftrightarrow B$)? A mutual swap occurs when Product A at Slot 1 must move to Slot 2, while Product B at Slot 2 must move to Slot 1 simultaneously on the same shelf. In these runs, swaps were 0 because products shifted unidirectionally.
    • True Collisions vs Multi-Facing POG Blocks: A true collision is when two different products (different UPCs) target the exact same slot. When multiple records of the same UPC target the same coordinate, it is simply multiple product facings sharing their planogram block anchor position.
